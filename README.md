## Keybinding

- arrows keys
- `a`,`w`,`s`,`d`
- and for vim user `h`,`j`,`k`,`l`
- q for quit application
- space for pause game#

## How to install SnakePie

make sure that you have `python3` installed
then install `pygame`

### Installing pygame

```bash
pip install pygame
```

### Installing SnakePie

clone the repo and run with `python`

```bash
git clone https://github.com/SureshAmal/snakepie.git
cd snakepie
python main.py
```
